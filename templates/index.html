API Documentation

You can also use our RESTful API to translate text programmatically.

POST /api/translate

{
  "text": "Hello",
  "source_lang": "en",
  "target_lang": "es"
}

Response:

{
  "success": true,
  "translation": "Hola",
  "source_lang": "en",
  "target_lang": "es",
  "original_text": "Hello"
}

GET /api/languages
